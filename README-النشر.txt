# Anime Codenames Online — خطوات النشر

هذه النسخة معدّة لتعمل على أربعة أجهزة عبر غرفة مشتركة باستخدام Firebase Realtime Database، ويمكن نشرها على رابط ويب يفتح في Google Chrome.

## 1) إنشاء مشروع Firebase
1. افتح https://console.firebase.google.com/ وأنشئ مشروعاً جديداً.
2. من إعدادات المشروع أضف تطبيق Web (أيقونة `</>`).
3. انسخ إعدادات `firebaseConfig` التي يعرضها Firebase.
4. من Authentication > Sign-in method فعّل Anonymous.
5. من Realtime Database أنشئ قاعدة بيانات.
6. افتح `index.html` واستبدل القيم التجريبية داخل `firebaseConfig` بالقيم التي نسختها.

## 2) قواعد قاعدة البيانات
من تبويب Realtime Database > Rules، ضع محتوى ملف `database.rules.json` ثم اضغط Publish.
هذه قواعد أولية لتجربة خاصة مع أصدقاء موثوقين وليست نظام حماية تنافسياً؛ لا تنشر رابط الغرفة للعامة.

## 3) النشر على Firebase Hosting
1. ثبّت Node.js ثم Firebase CLI على الكمبيوتر.
2. افتح الطرفية داخل هذا المجلد ونفّذ:
   `npm install -g firebase-tools`
3. سجّل الدخول:
   `firebase login`
4. اربط المجلد بمشروعك:
   `firebase use --add`
   واختر مشروع Firebase نفسه.
5. انشر الموقع:
   `firebase deploy`
6. سيظهر رابط Hosting مثل `https://اسم-مشروعك.web.app`. أرسله لأصدقائك وافتحوه في Chrome.

## طريقة اللعب
- منشئ الغرفة يضغط «إنشاء غرفة» ويرسل رمز الغرفة لأصدقائه.
- بقية اللاعبين يدخلون الرمز نفسه.
- كل لاعب يضغط زر لون واحد. اللون المحجوز يصبح غير متاح للاعبين الآخرين.
- بعد دخول أربعة لاعبين واختيار أربعة ألوان مختلفة، يبدأ منشئ الغرفة اللعبة.
- اللاعب الأول يرسل تلميح البداية مباشرة إلى اللاعب الثاني قبل كشف أول بطاقة.
- بعدها يختار اللاعب دوره بطاقة، ثم يرسل تلميحاً للاعب التالي.
